# Project Aurora Operations Brief

Project Aurora is a fictional orbital greenhouse controller operated by Northstar Labs.

The greenhouse's emergency rollback code is **CEDAR-71**. Operators should use the code only
after the temperature remains above 34°C for five consecutive minutes and the automatic cooling
cycle has failed twice.

Aurora's primary irrigation window begins at 03:40 UTC. Its backup reservoir contains 840 litres,
and the purple status light indicates that nutrient calibration is overdue.

For escalation, operators contact the fictional Aurora duty lead through channel `northstar-ops-7`.
